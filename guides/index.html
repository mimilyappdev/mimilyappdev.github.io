創作支援ガイド

小説づくり、同人イベント、依頼返信、締切管理。創作活動のまわりにある細かな作業を、少しだけ軽くするための読みものです。

RAKUNOVEL

小説同人誌の入稿PDFを作る方法

原稿整理、判型・余白設定、縦書き確認、書き出し後の点検までを順番に解説します。

読む →

RAKUNOVELCOVER

同人誌の表紙サイズ・背幅・塗り足し

表1・背表紙・表4をつないだ表紙データのサイズと注意点を整理します。

読む →

RAKUTTO

同人イベントの売上・在庫管理方法

搬入前の準備、当日の会計、撤収後の現物照合までを紹介します。

読む →

RAKUTHROUGH

確定申告前に創作活動の売上を整理する

BOOTH、イベント、依頼、決済サービスの数字を追える形にまとめます。

読む →

KOUSEIEASY

小説の字下げ・三点リーダーを整える方法

段落先頭、記号、空白など、原稿全体の表記をそろえる基本です。

読む →

EKAYELL

同じような文章表現が続くときの直し方

単純な類語交換に頼らず、感情やしぐさから描写を見直します。

読む →

SCHEDULEX

創作の締切を守るスケジュール管理

最終納期から工程を逆算し、複数案件を見通せる形にします。

読む →

EASYREPLY

依頼の受付・確認・お断り返信を作る

受付から納品まで、条件と次の行動が伝わる返信の組み立て方です。
